# What can it do ?

This software main use is in helping in the completion and response to bid solicitations in the electrical field.

In it's state (V2.0), the software will output the quantity of cable per circuit breaker in .csv files.

This way, you can choose the type of cable afterwards.

Using this tool also helps with creating your electric panel through the regrouping of equipments.
